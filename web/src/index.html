    Plot help

    Add trees and annotation tables with Add data, arrange cluster rows with Row order, and open Edit figure for data and appearance settings. File contains project saving and figure exports. Theme changes the interface appearance; System follows your device.

    Move around

    Scroll or pinch
    Zoom in and out around the pointer.
    Drag empty space
    Pan the figure. In Canvas/GPU mode, hold Space while dragging to pan over plotted items too.
    Minimap
    Click or drag in the overview to move to another part of a large plot.

    Select loci

    A locus is one sequence within a cluster. Selection highlights it and opens a batch-action toolbar.

    Shift + click
    Add or remove a locus from the selection. Clicking a gene with Shift selects its locus.
    Ctrl / ⌘ + Shift + click
    Add all loci in the cluster rows between the previous selection and this one.
    Alt / ⌥ + Shift + click
    Remove that range of cluster rows from the selection.
    Esc or Clear
    Clear plot selection when you are not typing in a field.

    Arrange and trim

    Drag a cluster label
    Reorder rows vertically. Dragging a selected cluster moves the selected rows as a block. An attached tree limits movement to orders that keep each clade together.
    Tree
    Choose a Newick tree with a new comparison or attach one using Add data → Import tree. Click an internal node to rotate its children. Use Row order to switch between the default order, an imported tree and the similarity dendrogram. The dendrogram shows gene-cluster similarity, not evolutionary ancestry. Right-click an internal node to style branches or clades and add text annotations. Edit figure contains tree appearance and dendrogram clade-colouring settings; hiding a tree retains its ordering constraints.
    Drag a locus track
    Move it horizontally. Dragging a selected locus moves all selected loci together.
    Double-click a locus
    Flip its orientation.
    Drag the end handles
    Hover over a locus to reveal handles, then drag an end to adjust its displayed bounds.
    Selection toolbar
    Flip selected loci, trim them to their outermost displayed genes, or restore their full bounds.

    Genes and legend

    Click a gene
    Anchor the figure on that gene, bringing linked genes into alignment.
    Right-click a gene
    Open its label, colour and anchoring controls.
    Click legend text or colour
    Rename a group or change its colour. Right-click its text for more group controls.
    Click the scale bar
    Change the length represented by the bar.

    Batch editing

    Edit figure
    Open the bottom panel to edit genes, groups, links, annotation panels and appearance settings. Choose Close editor to return to the full figure.
    Select rows or checkboxes
    Apply actions to multiple records. In the Genes tree, a cluster or locus checkbox selects its genes; Shift-click selects a range of rows.
    Group actions
    Assign genes to groups, create or merge groups, and set shared labels, colours or visibility. Drag a group’s reorder grip, or focus it and use ↑ / ↓, to reorder the legend.
    Undo / Redo
    Use the buttons at the top of the editor to reverse or reapply figure edits. Enter commits an inline field; Esc cancels it.

    Save your work

    Add data → Import annotations
    Load a TSV or CSV with one row per cluster and a header row. File and matching options lets you change the cluster identifier column; unmatched rows can be assigned or skipped. Separate tracks gives each selected column its own scale or legend. One heatmap combines selected columns with a shared scale for comparable measurements such as gene expression or 0/1 presence and absence. Values are not normalised. Review the scale beside each column before importing. Identifier and high-cardinality columns start skipped. Imported panels are saved with the project.
    File → Save project
    Save the analysis, appearance and edits. Use File → Open project to continue later; work is not saved automatically.
    File → Export figure (SVG)
    Download the figure for publication or further editing.
    File → Export similarity table (CSV)
    Download analysis scores with current cluster names and plot order. Visual edits do not recompute scores.

    About clinker

    clinker compares gene clusters, groups homologous proteins and arranges the results as an interactive figure. It is available in a browser and as a command-line application.

    Your input files and analysis stay on your device. Save a project to keep your edits and continue later; work is not saved automatically.
