    Plot help

    Arrange, edit and export your comparison with the menus above the figure. Your files stay in the browser; save a project to keep your work.

    Navigate and select

    Zoom and pan
    Scroll or pinch to zoom. Drag empty space to pan; in Canvas/GPU mode, hold Space to pan over the figure.
    Minimap
    Click or drag the overview to move around a large figure.
    Select loci
    Click a locus. Shift-click toggles it; Shift-click a gene to select its locus.
    Select a row range
    Ctrl/⌘ + Shift-click adds the range. Alt/⌥ + Shift-click removes it.
    Clear selection
    Press Esc or choose Clear when you are not typing in a field.

    Arrange and trees

    Move rows
    Drag a cluster label. Selected rows move together; an active tree keeps each clade together.
    Move or resize loci
    Drag a locus to move it. Drag an end handle to change its displayed bounds; double-click to flip its orientation.
    Trim selected loci
    Use the selection toolbar to flip, trim to displayed genes, or restore full bounds.
    Choose a tree
    Import Newick with Add data or when starting a comparison. Row order switches between Default, an imported tree and the Similarity dendrogram. The dendrogram shows gene-cluster similarity, not ancestry.
    Edit a tree
    Right-click a node for tree controls. Depending on the tree and node, you can root or rotate branches, collapse a clade, style it, or add a label. Tree appearance is under Row order.

    Edit the figure

    Gene and group shortcuts
    Click a gene to anchor it; right-click to edit its label or colour. Click legend text or colour to rename or recolour a group; right-click for more actions.
    Edit figure
    Open the editor to make batch changes to genes, groups, links, annotations and appearance. Select rows or checkboxes; use Undo and Redo to review edits.
    Scale bar
    Click it to change the represented length.

    Add data and save

    Import annotations
    Use a TSV or CSV with a header and one row per cluster. Choose separate panels or group comparable columns into heatmaps with shared scales and palettes.
    Save or open a project
    Use File → Save project or Open project. Edits are not saved automatically.
    Export
    SVG exports the figure. The similarity CSV exports analysis scores; visual edits do not change them.

    About clinker

    clinker compares gene clusters and arranges their similarities as an interactive figure. Browser analysis runs on your device. Theme changes the interface, not figure colours.
